ГЕНЕРАТОР ФИКТИВНЫХ ТЕСТОВЫХ ИДЕНТИФИКАТОРОВ

Содержимое:
- pinfl_test_generator.py — исходный код приложения;
- build_exe_windows.bat — сборка Windows EXE.

Как собрать EXE:
1. Установите Python 3.10 или новее с сайта https://www.python.org/downloads/windows/
   При установке включите "Add Python to PATH".
2. Распакуйте архив в отдельную папку.
3. Дважды щёлкните build_exe_windows.bat.
4. После сборки файл появится в dist\PINFL_Test_Generator.exe.

Работа:
- Укажите начальный порядковый номер.
- Укажите количество записей.
- Нажмите «Создать XLSX» и выберите место сохранения.

ВАЖНО:
Это генератор исключительно синтетических тестовых значений.
Все значения начинаются с зарезервированного тестового префикса 999.
Последняя цифра вычисляется по отдельному тестовому алгоритму (сумма цифр modulo 10),
а не по официальному алгоритму ПИНФЛ.
Значения не являются ПИНФЛ и не предназначены для идентификации граждан.
Не используйте их в продуктивных системах.

ОНЛАЙН-СБОРКА ЧЕРЕЗ GITHUB ACTIONS:
1. Создайте на GitHub новый пустой репозиторий.
2. Загрузите в него все файлы из этого архива, включая скрытую папку .github.
3. Откройте вкладку Actions.
4. Выберите workflow "Build Windows EXE" и нажмите Run workflow.
5. После завершения сборки откройте результат запуска и скачайте артефакт
   PINFL-Test-Generator-Windows в разделе Artifacts.
